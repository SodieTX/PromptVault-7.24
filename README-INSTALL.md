# Prompt Vault 7.25.3 — Chrome installation

1. Get the extension folder onto disk in a stable location (clone this repository, or extract a release ZIP — do not load a ZIP directly).
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Choose **Load unpacked**.
5. Select the folder containing `manifest.json`.

If updating an existing unpacked Prompt Vault, point Chrome at the new folder (or press the reload arrow on the extension card) and confirm Chrome shows version **7.25.3**. Your vault data is stored by Chrome; do not clear extension storage while updating.
